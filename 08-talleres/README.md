# 08. Talleres de inteligencia artificial

Carpeta de prácticas organizadas por tema.

## Trabajo disponible

Los talleres permiten explorar distintas formas de construir soluciones de IA. En algoritmos evolutivos se representan recorridos de un laberinto como secuencias de movimientos y se aplica un algoritmo genético para mejorar una población de soluciones. En lógica difusa se trabaja con grados de pertenencia y reglas para calcular una propina a partir de la calidad de la comida y el servicio. En FNN se construye y entrena desde cero una red neuronal con NumPy para clasificar dígitos manuscritos de MNIST.

El material combina código y visualizaciones para revisar cómo se obtiene una solución, no solo su valor final. El taller evolutivo incluye gráficas del recorrido y del fitness; el de lógica difusa incluye operaciones básicas, reglas de inferencia y varios casos de entrada.

FNN incluye un notebook con el desarrollo, las gráficas y la evaluación de la red. NLP incluye un analizador de sentimientos por vocabulario y reglas, con una interfaz interactiva de consola para clasificar frases en español.
