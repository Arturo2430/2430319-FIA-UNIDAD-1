## Trabajo de la unidad

Las actividades reúnen la preparación del entorno de Python, el estudio de la historia de la inteligencia artificial y la organización de conceptos sobre agentes inteligentes. Después se incluyen prácticas de limpieza de datos con Bash y ejercicios de lógica proposicional, que relacionan la formulación de reglas con el comportamiento de un sistema.

La parte práctica también contiene un proyecto de investigación y redacción de noticias con CrewAI, talleres de algoritmos evolutivos y lógica difusa, y el firmware de una máquina expendedora controlada por estados. Según la actividad, las evidencias se presentan como reportes PDF, fuentes LaTeX, notebooks, scripts, datos procesados o código para Arduino.
