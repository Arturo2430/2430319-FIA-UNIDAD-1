# 01. Configuración del entorno de desarrollo

Actividad de preparación del entorno de trabajo para las prácticas de inteligencia artificial.

## Trabajo realizado

Se documentó la instalación de un entorno virtual de Python y de las herramientas necesarias para trabajar con notebooks. La actividad incluye capturas del entorno y una prueba de importación de IPython, Notebook, NumPy, Matplotlib, SciPy y scikit-learn en `config.ipynb`.

Esta comprobación permite revisar que las librerías estén disponibles antes de comenzar las prácticas de análisis de datos e inteligencia artificial. El reporte también incorpora una investigación técnica manuscrita sobre Python en la Ingeniería e Innovación Digital, junto con las evidencias de instalación e importación.

## Evidencia

El PDF reúne la documentación de la actividad; `main.tex` permite editar el reporte y `figs/` conserva las imágenes utilizadas. El notebook contiene la comprobación de importaciones, por lo que no corresponde a un entrenamiento de modelos.

## Contenido

- `Actividad 1 - Configuración de entorno de desarrollo.pdf`: documento de la actividad.
- `config.ipynb`: notebook de trabajo.
- `main.tex`: fuente del reporte en LaTeX.
- `figs/`: capturas de instalación e imágenes del reporte.

Consulta el PDF para revisar la actividad y abre el notebook en Jupyter o Visual Studio Code para explorar el código.
